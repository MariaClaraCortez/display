# 📐 Estudo de Display — HTML & CSS

Projeto desenvolvido para estudar os principais valores da propriedade `display` do CSS e entender, na prática, como cada um deles altera o comportamento e o posicionamento dos elementos na página.

## 🎯 Objetivo

Explorar e comparar diferentes tipos de `display`, observando suas características, comportamentos e situações em que cada um pode ser utilizado.

## 🧩 Displays estudados

| Display | Descrição |
|---|---|
| `block` | Ocupa toda a largura disponível e inicia uma nova linha. |
| `inline` | Permite que elementos permaneçam na mesma linha, respeitando o fluxo do texto. |
| `inline-block` | Combina características de `inline` e `block`. |
| `flex` | Facilita o alinhamento e a distribuição de elementos em uma dimensão. |
| `grid` | Permite criar layouts organizados em linhas e colunas. |
| `none` | Remove o elemento do layout e faz com que ele não seja exibido. |

## 📊 Dados de uso

O projeto apresenta exemplos para comparar os diferentes valores de `display`, facilitando a visualização de:

- comportamento dos elementos;
- ocupação de espaço;
- alinhamento;
- posicionamento;
- diferenças entre `flex` e `grid`;
- situações recomendadas para cada propriedade.
